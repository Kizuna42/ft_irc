# ft_irc ドキュメント索引

## 📚 ドキュメント概要

このドキュメント群は、ft_irc プロジェクト（C++98 で実装された IRC サーバー）の完全な技術ドキュメントです。初学者でも短時間でシステム全体を理解できるよう、基礎知識からプロジェクト固有の実装まで詳細に説明しています。

## 🎯 対象読者

- IRC サーバーの実装を理解したい開発者
- ft_irc プロジェクトに参加する新しいメンバー
- C++98 での非ブロッキング I/O を学びたい方
- IRC プロトコルの実装を学びたい方

## 📖 ドキュメント一覧と読む順序

### 第 1 部: 基礎知識（必読）

#### [01_BASICS.md](01_BASICS.md) - 基礎知識

**推定読了時間: 30-45 分**

IRC プロトコル、C++98 の制約、非ブロッキング I/O の基礎を学びます。

**内容:**

- IRC プロトコルとは何か
- メッセージフォーマット（prefix, command, params, trailing）
- 数値応答コードの仕組み
- 認証フロー（PASS → NICK → USER）
- C++98 の制約と使用可能な機能
- 非ブロッキング I/O と poll() の仕組み
- fcntl() での非ブロッキング設定

**こんな人におすすめ:**

- IRC プロトコルを初めて学ぶ方
- poll() を使った非ブロッキング I/O の経験がない方

## 💡 ドキュメントの使い方

### 初めて読む方

1. **01_BASICS.md** から順番に読むことをおすすめします
2. コード例は実際に手を動かして試してみましょう
3. 理解が難しい部分は飛ばして、後で戻ってきても大丈夫です

### 実装中の方

- 各ドキュメントは独立しているので、必要な部分だけ参照できます
- クイックリファレンスを活用して、必要な情報を素早く見つけましょう
- コード例は実際のプロジェクトコードから引用しているので、そのまま参考にできます

### レビュー・メンテナンス担当の方

- **02_ARCHITECTURE.md** でシステム全体を把握
- **09_DATA_FLOW.md** でデータの流れを確認
- **12_IMPLEMENTATION_TIPS.md** でベストプラクティスを確認
